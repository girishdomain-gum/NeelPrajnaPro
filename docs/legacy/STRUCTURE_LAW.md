# docs\ — THE STRUCTURE LAW
*Version 2.0 · 2026-07-29 · Owner rulings: one document per thing · one folder per thing · md and docx twins share basename AND location · versions live inside documents and in git; parallel documents are forbidden. A new folder may be created only for a genuinely new THING, and this index must name it.*

## The uniform rule
Every thing owns one folder. Inside it: exactly one current master, named `NeelPrajnaPro_<Thing>-vX.Y.md`. Where a human render exists, it is `NeelPrajnaPro_<Thing>-vX.Y.docx` — the SAME document in a second form, same basename, same folder; divergence between the two forms is a finding. On supersession the old version auto-moves to archive\; git preserves everything regardless. The journal alone carries no version suffix — it is append-only and never superseded.

## The law, in three lines
1. Update the doc; never fork it. History = git + the doc's own Change Record.
2. Logs append to the journal only. A second changelog anywhere is a finding.
3. One folder, one basename, current version only — a second basename in a thing-folder is a finding.
